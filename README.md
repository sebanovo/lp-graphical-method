# Programación Lineal - Método Gráfico

## Descripción
Esta es una herramienta visual para resolver problemas de programación lineal mediante el método gráfico. Permite a los usuarios ingresar una función objetivo y un conjunto de restricciones, visualizando gráficamente la región factible y la solución óptima.

## Características
- Interfaz intuitiva para ingresar la función objetivo y restricciones
- Visualización gráfica de la región factible
- Soporte para problemas de maximización y minimización
- Opción para forzar variables no negativas
- Detección y visualización del punto óptimo

## Limitaciones y Advertencias
⚠️ **IMPORTANTE**: Este proyecto es una implementación educativa y no debe utilizarse para aplicaciones profesionales o críticas. Presenta limitaciones en:

- El manejo de problemas con más de 2 variables (limitación inherente del método gráfico)
- La precisión en cálculos con números decimales muy pequeños o muy grandes
- El tratamiento de casos especiales como regiones no acotadas o soluciones múltiples
- La validación exhaustiva de todas las entradas posibles

Este software se proporciona "TAL CUAL", sin garantías de ningún tipo. Está destinado únicamente para fines educativos, de curiosidad y aprendizaje.

## Uso
1. Seleccione si desea maximizar o minimizar la función objetivo
2. Ingrese los coeficientes de la función objetivo (c1 para x1, c2 para x2)
3. Añada las restricciones utilizando el formato: ax₁ + bx₂ ≤ c
4. Haga clic en "Resolver" para visualizar la solución

## Tecnologías Utilizadas
- HTML5
- Tailwind CSS
- Plotly.js (para visualizaciones gráficas)
- JavaScript Vanilla
